# Yiğiter Tarım Ürünleri Showcase

Modern tarım teknolojileri ve kaliteli ürünlerle üreticilerin yanında. Zirai ilaç, gübre, tohum, damla sulama sistemleri ve tarım teknolojileri.

## Local Development

1. Install dependencies:
   ```sh
   npm install
   ```

2. Start the development server:
   ```sh
   npm run dev
   ```

3. Build for production:
   ```sh
   npm run build
   ```

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Shadcn UI
